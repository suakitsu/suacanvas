三、API 接入方案（三路）
主力通道

APIMart

OpenAI 官方授权合作，DALL-E 3 稳定性最高，可开增值税发票，企业客户首选，价格略高但信任度强。

补充通道

APIyi（API易）

价格比 APIMart 低一档，模型覆盖广（Flux / SDXL / MJ 系列均有）。主力故障时切换，或承接开源模型任务。

自建中转

自己的中转站

成本最低，自控 Key 池和限流策略。专门跑高频低价任务（批量草图、预览出图），最大化利润空间。

AI 写真 & 数字形象区

个人头像 · 职业写真 · 小红书人设图 · 古风写真 · IP 形象

随缘发挥 ★

这个区最大的价值不是直接变现，而是自带裂变属性——用户生成完 AI 写真会主动发小红书/朋友圈，每一条都是免费广告。技术上和普通生图没有本质区别，门槛低，引流价值高。

  • AI 职业头像：上传 1–3 张自拍 → 商务风/创意风/学术风职业照（LinkedIn / 简历 / 官网用）
  • 小红书人设图：网红感、氛围感、旅行风，博主专属风格
  • 古风 / 汉服写真（分享欲最强，裂变效果最好）
  • 情侣写真 / 宝宝写真：高情感价值，节日礼物场景，付费意愿强
  • 个人 IP 形象 / 吉祥物草稿：自媒体人、品牌主的专属 IP 卡通参考稿
💡 运营技巧：在小红书发「AI 写真 vs 真实拍摄」对比帖配平台链接，这个区最容易跑出 10 万+ 引流帖

图片生成核心流程
  1. 用户选择分区场景 → 填写参数（产品名 / 颜色 / 风格 / 尺寸）
  2. 前端调用 /api/generate，携带场景模板 ID + 用户参数
  3. 后端将参数注入提示词模板，生成最终 Prompt（自动中英双语拼接）
  4. API 路由器判断优先级：品质任务 → APIMart；性价比 → APIyi；批量低价 → 自建中转
  5. API 返回图片 URL / Base64 → 后端下载 → 压缩 → 上传 OSS → 返回 CDN 链接
  6. 扣除用户积分，写入生成记录（用户ID / 参数 / 模型 / 成本 / 图片URL）
  7. WebSocket 推送完成通知，前端渲染结果图
💡 API 路由器写一个简单的优先级队列 + 失败重试逻辑即可，100 行内搞定。主力挂了自动 fallback 到下一路，不需要手动干预。

工作台核心功能
  • 场景选择器：左侧分区导航（图标 + 文字），点击进入对应模板
  • 参数面板：表单化替代手写 Prompt，核心参数 ≤ 5 个，其余折叠为「高级设置」
  • 风格预设：每个模板 4–8 种风格一键切换，有缩略图预览
  • 尺寸选择器：各平台标准尺寸快选 + 自定义宽高
  • 数量选择：1 / 2 / 4 张同时生成（多张享积分折扣）
  • 参考图上传：图生图，上传参考图作为风格 / 构图参考
  • 实时进度：WebSocket 推送（排队中 → 生成中 → 完成）
图片结果页功能
  • 一键下载（原图 / 压缩图 / 转 PNG/WebP）
  • 复用参数（一键再生，微调单个参数）
  • 图片变体（基于结果生成 4 个变体）
  • 放大 2x / 4x（AI 超分，Real-ESRGAN）
  • 去背景（白底图一键抠图，调用 remove.bg 或 BRIA API）
  • 收藏 / 相册管理，历史记录保存 90 天（企业版永久）
